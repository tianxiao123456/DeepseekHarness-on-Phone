# DSH Phone

在手机浏览器里使用这台电脑上的 **DeepSeek Harness**：查看工作区、翻看历史对话、
新建会话、发指令、看它执行工具，并在动手前确认敏感操作。

- 手机浏览器直接打开，**不用装 App**
- 电脑上双击一次即可，**不用配置服务器、不用注册账号**
- 出门用流量也能连（自动建立公网加密隧道）
- 界面按 **iPhone 16 Pro（402 × 874）** 设计，同时适配其它手机

---

## 快速开始

1. 确保电脑上装好了 **DeepSeek Harness 桌面版**，并已登录（能正常对话）。
2. 双击 **`启动 DSH Phone.cmd`**。
3. 电脑会弹出配对页，显示二维码、地址和 6 位访问码。
4. 手机扫码（或浏览器输入地址），首次输入访问码即可。

> 访问码每次启动都会变，只显示在电脑上。关闭启动窗口 = 立即断开手机访问。

启动后电脑上会打印类似内容：

```
✓ 公网地址 https://xxxxxxxx.lhr.life
访问码  123456
```

同一条 Wi-Fi 下会自动走局域网；检测不到公网隧道时也会退回局域网模式，
这时需要手机和电脑在同一 Wi-Fi。

## 手机上能做什么

| 功能 | 说明 |
|---|---|
| 工作区 | 抽屉里列出电脑端登记的所有工作区，点一下就在该目录新建会话 |
| 历史对话 | 直接读取电脑端的会话记录，点开即可翻看（只读） |
| 继续会话 | 会话没被电脑占用时点「继续这个会话」直接接管；被占用时弹出「不能直接接管」，可一键「复制这段对话，继续聊」 |
| 新建会话 | 指定电脑上的绝对路径，Harness 在该目录工作 |
| 实时输出 | 回复、思考过程、工具调用（命令、读写文件）实时显示 |
| 权限确认 | 敏感操作弹底部确认条，允许 / 拒绝由你决定 |
| 模型切换 | 右上角模型按钮，选择模型与推理强度 |
| 计划与用量 | 执行计划浮条、上下文用量条 |

历史记录是**只读**的：不会改动电脑上的会话文件，也不会和桌面端抢同一个会话。

**关于「继续这个会话」**：桌面端正在使用某条会话时，Harness 会拒绝第二个进程写入
（错误提示为 `already owned by an active write handle`）。手机端会把这种情况翻译成
「不能直接接管」，并提供两个选择：

- **复制这段对话，继续聊**：新建一个会话，把原会话最近的对话摘录作为上下文带过去，
  电脑上的原会话完全不受影响；
- **先只看历史**：留在只读回放。

如果那条会话没有被桌面端占用（例如桌面端已关闭该会话），点「继续这个会话」会直接接管，
后续消息写回原会话。

## 它是怎么工作的

```
手机浏览器  ──HTTPS/WSS──▶  公网隧道  ──▶  本机 bridge  ──ACP(stdio)──▶  dsh --profile acp
                                              │
                                              └──只读──▶  %USERPROFILE%\.dsh\sessions（桌面端历史）
```

- `app/bridge.js`：本机 HTTP/WebSocket 服务 + 访问码校验 + ACP 客户端
- `app/store.js`：只读解析桌面端的 `workspace.json` 与会话日志（zstd 多帧 JSONL）
- `app/launcher.js`：找 Harness、开隧道、打印二维码、拉起 bridge
- `app/web/`：手机端界面（原生 JS，无框架、无外部请求）

隧道优先用系统自带的 `ssh` 连接 `localhost.run`（免注册、免下载）；
不可用时自动尝试 Cloudflare 快速隧道；都失败则退回局域网。

## 安全

- 所有页面（除登录页/配对页）都需要 **6 位访问码**换取的 Cookie，10 次错误锁定 10 分钟
- 配对页（含二维码和访问码）**只允许本机访问**，经隧道访问会被 403
- 隧道是出站连接，电脑不开放任何入站端口；不需要改路由器、不需要公网 IP
- 访问码和隧道地址每次启动都会更新；关掉窗口就断开
- 建议：不在公共电脑上启动；不用时关掉窗口

## 常见问题

**双击后提示找不到 Harness**
程序会依次查找 `%LOCALAPPDATA%\Programs\DeepSeek Harness`、`Program Files`、
`E:\Deepseek Harness` 等位置；也可以手动指定：

```bat
node app\launcher.js --cli "D:\你的安装目录\resources\runtime\cli\bin\dsh.cmd"
```

**手机打开一直显示「正在连接电脑…」**
- 确认电脑上的启动窗口没有关掉
- 公网隧道断开时窗口会提示，重启窗口即可（地址会变，重新扫码）
- 同一 Wi-Fi 下可以用局域网地址访问

**没有公网隧道 / 公司网络限制**
加 `--no-tunnel` 只用局域网：

```bat
node app\launcher.js --no-tunnel
```

**只想先看看界面**
演示模式不会连电脑、不花钱：

```bat
node app\launcher.js --demo
```

**支持哪些系统**
Windows 10/11（自带 OpenSSH 客户端与 Node 运行时二选一即可）。
手机端 Safari / Chrome / Edge 均可，iOS 可「添加到主屏幕」当 App 用。

## 命令参数

| 参数 | 作用 |
|---|---|
| `--pin 123456` | 固定访问码（默认随机） |
| `--cwd D:\work` | 新建会话的默认目录 |
| `--no-tunnel` | 不建公网隧道，仅局域网 |
| `--demo` | 演示模式，假数据 |
| `--cli <path>` | 指定 `dsh.cmd` 路径 |
